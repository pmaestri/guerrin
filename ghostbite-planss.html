Plan de Implementación Paso a Paso

🍔 GhostBite — Dark Kitchen

Todo creado desde la consola de AWS y AWS CLI. Sin Terraform, sin GitOps. Foco en arquitectura y servicios.
Enfoque: toda la infraestructura se crea desde la consola web de AWS o con AWS CLI. El código de las Lambdas se sube directamente con un .zip o desde el editor inline de la consola. El repo de GitHub se usa solo para versionar el código, sin pipelines automatizados.

Escribir los ADRs (Architecture Decision Records)

# docs/adr/001-kafka-vs-sqs.md ## ADR-001: Usar Amazon MSK (Kafka) en lugar de SQS ### Contexto Necesitamos un bus de eventos que soporte múltiples consumidores del mismo mensaje (fan-out nativo) con orden garantizado por partición. ### Decisión MSK porque: - Fan-out nativo con consumer groups (SQS necesitaría SNS+SQS por cada consumer) - Orden garantizado por partition key (orderId) - Retención de mensajes para replay en caso de error - Throughput alto para picos ### Consecuencias - Mayor complejidad que SQS - Costo base más alto (brokers always-on vs pay-per-message) - Requiere VPC y networking dedicado

Crear Infraestructura en AWS (Consola + CLI)
Martes — 4 a 6 horas
1
Crear la VPC con subnets
MSK y ElastiCache necesitan VPC. Creá una con el wizard de la consola que genera todo automáticamente.
🖥️ Consola: VPC → Create VPC → "VPC and more" → Name: ghostbite → 2 AZs → 2 public + 2 private subnets → NAT Gateway: In 1 AZ → Create.
💡 El wizard "VPC and more" te crea subnets, route tables, internet gateway y NAT gateway en un click. Ahorrás 30 minutos.
2
Crear el cluster MSK Serverless
MSK Serverless es la opción más simple y barata para un TP. No tenés que elegir instancias ni gestionar brokers.
🖥️ Consola: Amazon MSK → Create cluster → Serverless → Name: ghostbite-kafka → Seleccioná la VPC ghostbite y las 2 subnets privadas → IAM authentication → Create.
Después de crearlo (tarda ~15 min), anotá el Bootstrap servers del panel "View client information". Lo vas a necesitar en las Lambdas.
3
Crear las tablas DynamoDB
Dos tablas: Orders y Menu.
🖥️ Consola: DynamoDB → Create table
• Table 1: Name=ghostbite-orders, PK=orderId (String), SK=timestamp (Number), Settings=On-demand
• Table 2: Name=ghostbite-menu, PK=itemId (String), Settings=On-demand
Después de crear Orders, agregá los GSIs:
🖥️ Consola: ghostbite-orders → Indexes tab → Create index
• GSI 1: PK=channel (String), SK=timestamp (Number), name=channel-index
• GSI 2: PK=status (String), SK=timestamp (Number), name=status-index
4
Crear Cognito User Pool
Para autenticar a los clientes que usan la API.
🖥️ Consola: Cognito → Create user pool → Email sign-in → Default password policy → No MFA (para simplificar) → Name: ghostbite-users → Create.

Después: App integration tab → Create app client → Name: ghostbite-app → Auth flows: ALLOW_USER_PASSWORD_AUTH → Create.
Anotá: User Pool ID y App Client ID. Crea un usuario de test:

Crear bucket S3

Lambda Ingress + API Gateway + Primer Consumer
Miércoles — 5 a 7 horas
1
Desarrollar la Lambda Ingress
Recibe el POST, valida el pedido, genera orderId y publica al topic "pedidos" de Kafka. Escribí el código localmente.
# lambdas/ingress/handler.py import json, os, uuid, base64 from datetime import datetime from kafka import KafkaProducer from aws_msk_iam_sasl_signer import MSKAuthTokenProvider def get_producer(): """Crea producer con IAM auth para MSK Serverless""" tp = MSKAuthTokenProvider(region=os.environ['AWS_REGION']) return KafkaProducer( bootstrap_servers=os.environ['MSK_BOOTSTRAP'].split(','), security_protocol='SASL_SSL', sasl_mechanism='OAUTHBEARER', sasl_oauth_token_provider=tp, value_serializer=lambda v: json.dumps(v).encode() ) def handler(event, context): body = json.loads(event['body']) # Validar campos for field in ['items', 'deliveryAddress']: if field not in body: return {'statusCode': 400, 'body': json.dumps({'error': f'Falta {field}'})} # Extraer customerId del JWT (viene de Cognito) customer_id = event['requestContext']['authorizer']['jwt']['claims']['sub'] # Generar evento order_id = str(uuid.uuid4()) order_event = { 'eventType': 'ORDER_CREATED', 'timestamp': datetime.utcnow().isoformat() + 'Z', 'data': { 'orderId': order_id, 'channel': body.get('channel', 'app'), 'customerId': customer_id, 'items': body['items'], 'total': sum(i['price'] * i['qty'] for i in body['items']), 'deliveryAddress': body['deliveryAddress'], 'status': 'RECIBIDO' } } # Publicar a Kafka producer = get_producer() producer.send('pedidos', key=order_id.encode(), value=order_event) producer.flush() return { 'statusCode': 201, 'headers': {'Content-Type': 'application/json'}, 'body': json.dumps({ 'orderId': order_id, 'status': 'RECIBIDO', 'message': 'Pedido recibido!' }) }

# lambdas/order-processor/handler.py import json, boto3, base64, time dynamodb = boto3.resource('dynamodb') table = dynamodb.Table('ghostbite-orders') def handler(event, context): for topic, records in event['records'].items(): for record in records: payload = json.loads( base64.b64decode(record['value']).decode() ) data = payload['data'] table.put_item(Item={ 'orderId': data['orderId'], 'timestamp': int(time.time()), 'channel': data['channel'], 'status': data['status'], 'customerId': data['customerId'], 'items': data['items'], 'total': str(data['total']), # DynamoDB no acepta float 'deliveryAddress': data['deliveryAddress'], 'timestamps': { 'received': payload['timestamp'] } }) print(f"Order {data['orderId']} saved to DynamoDB") return {'statusCode': 200}

Consumers Restantes + Redis + WebSocket
Jueves — 5 a 7 horas
1
Desarrollar KitchenManager consumer
Consume de "pedidos", actualiza estado en Redis a EN_PREPARACIÓN, agrega a la cola de cocina.
# lambdas/kitchen-manager/handler.py import json, os, base64, redis from datetime import datetime r = redis.Redis(host=os.environ['REDIS_HOST'], port=6379, ssl=True) def handler(event, context): for topic, records in event['records'].items(): for record in records: payload = json.loads(base64.b64decode(record['value']).decode()) data = payload['data'] order_id = data['orderId'] # Estado en Redis r.hset(f"order:{order_id}", mapping={ 'status': 'EN_PREPARACION', 'updated_at': datetime.utcnow().isoformat(), 'items': json.dumps(data['items']) }) r.expire(f"order:{order_id}", 7200) # Cola de cocina r.lpush("kitchen:queue", order_id) print(f"Order {order_id} → kitchen queue") return {'statusCode': 200}
🖥️ Consola: Lambda → Create → ghostbite-kitchen-manager → misma config. Env var: REDIS_HOST. Trigger: MSK → topic: pedidos.
2
Desarrollar StockUpdater consumer
Consume de "pedidos", descuenta stock de cada item en DynamoDB (tabla Menu). Si stock < 5, logea una alerta.
# lambdas/stock-updater/handler.py import json, boto3, base64 dynamodb = boto3.resource('dynamodb') menu_table = dynamodb.Table('ghostbite-menu') def handler(event, context): for topic, records in event['records'].items(): for record in records: payload = json.loads(base64.b64decode(record['value']).decode()) for item in payload['data']['items']: menu_table.update_item( Key={'itemId': item['itemId']}, UpdateExpression='SET stock = stock - :qty', ExpressionAttributeValues={':qty': item['qty']}, ReturnValues='UPDATED_NEW' ) return {'statusCode': 200}
🖥️ Consola: Lambda → Create → ghostbite-stock-updater. Trigger: MSK → topic: pedidos.
💡 Cargá algunos items de test en la tabla Menu antes de probar: burger_01 con stock=100, fries_01 con stock=50, etc.
3
Desarrollar DeliveryTracker consumer
Consume de "pedidos", simula asignación de repartidor, actualiza Redis con EN_CAMINO. En un sistema real acá irían las coordenadas GPS.
# lambdas/delivery-tracker/handler.py import json, os, base64, redis, random r = redis.Redis(host=os.environ['REDIS_HOST'], port=6379, ssl=True) DRIVERS = ['driver_01', 'driver_02', 'driver_03', 'driver_04'] def handler(event, context): for topic, records in event['records'].items(): for record in records: payload = json.loads(base64.b64decode(record['value']).decode()) data = payload['data'] order_id = data['orderId'] # Asignar repartidor (round-robin simplificado) driver = random.choice(DRIVERS) r.hset(f"order:{order_id}", mapping={ 'status': 'EN_CAMINO', 'driver': driver }) print(f"Order {order_id} assigned to {driver}") return {'statusCode': 200}

# lambdas/notifier/handler.py import json, boto3, os, base64 sns = boto3.client('sns') ses = boto3.client('ses') TOPIC_ARN = os.environ['SNS_TOPIC_ARN'] SENDER = os.environ['SES_SENDER'] def handler(event, context): for topic, records in event['records'].items(): for record in records: payload = json.loads(base64.b64decode(record['value']).decode()) data = payload['data'] # Push via SNS sns.publish( TopicArn=TOPIC_ARN, Subject=f"Pedido {data['orderId'][:8]}", Message=f"Tu pedido fue recibido!\n" f"Items: {len(data['items'])}\n" f"Total: ${data['total']}\n" f"Estado: {data['status']}" ) # Email via SES (en sandbox, ambos emails deben estar verificados) ses.send_email( Source=SENDER, Destination={'ToAddresses': ['test@ghostbite.com']}, Message={ 'Subject': {'Data': f'Confirmación pedido {data["orderId"][:8]}'}, 'Body': {'Text': {'Data': f'Gracias por tu pedido! Total: ${data["total"]}'}} } ) return {'statusCode': 200}

• ElastiCache: cache.t3.micro = ~$12/mes
• API Gateway: 1000 requests/día = ~$1/mes
• SNS + SES: negligible en free tier
